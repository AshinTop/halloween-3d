# Ghost Lanterns 3D — ハロウィンの Lights Out 点灯パズル

🎃 ひと押しで、夜の景色が少し変わります。Ghost Lanterns 3D は、Lights Out のルールをかぼちゃの庭にしたパズル。紫色の魂のつながりを見ながら、すべての灯りをともしておばけを迎えましょう。12の問題と日替わりの庭を、自分のペースで楽しめます。

**[ブラウザーで遊ぶ](https://halloween-3d.crazy3d.org/)** · [全12作のハロウィンゲームを見る](https://github.com/AshinTop/halloween-games) · [⭐ GitHub で Star を付ける](https://github.com/AshinTop/halloween-3d)

## このゲームの楽しみ方

- 3×3 と 4×4 の盤面による12の庭。目標はすべてのランタンを点灯すること。
- レベル5から魂のペアが登場し、特定のクリックに追加のつながりが生まれます。
- 立体形状、光、回転カメラを持つ3Dシーン。ソフトウェア3Dと平面盤面も用意。
- 回数制限のない Undo とやり直し、現在の状態から最少クリック数を求めるヒント。
- UTC 基準の日替わり問題、初期盤面の共有、端末内記録、任意のベル音と動きを抑える設定。

## 基本ルール

ランタンを押すと、その灯りと**上下左右の隣の灯り**が反転します。点灯中なら消灯、消灯中なら点灯です。端や角は通常の隣接ランタンが少なくなります。庭が全部明るくなればクリア。時間や総手数の制限はありません。

レベル5から、紫色で示した魂のペアが登場します。どちらかを**直接押したときだけ**、相手も1回反転します。隣接の効果で変わった灯りから、さらに魂の効果が伝わることはありません。ペアの相手が通常の隣接範囲にも入る場合も、反転は1回だけです。

Undo は1手前へ戻し、Hint は今の盤面から最少クリックで解くための次の一手を教えます。表示される最短ルートの数値は開始盤面のものです。主線の全問題に解があり、日替わりの庭も完成形に合法な操作を加えて作るため解けます。

## 操作方法

| 操作 | 入力 |
| --- | --- |
| ランタンを反転 | クリック・タップ、または選択中のボタンで**Enter / スペース** |
| ランタンを選ぶ | 庭にフォーカスがあるとき矢印キー |
| 戻す・やり直す・ヒント | **U / R / H** または各ボタン |
| 庭を回転 | 表示されている左右のカメラボタン |
| 平面盤面へ切り替え | 表示切り替えボタン |
| 庭・日替わり・共有 | 対応するゲーム内ボタン |

## ちょっとしたコツ

点けたい1つだけでなく、変化する十字全体を見ましょう。一度消すことが、最後の一手への準備になる場合もあります。同じランタンを2回押すと盤面は元に戻るので、同じ操作が続いたら別のルートを考える合図です。魂のつながりが反応するのは、直接押した灯りだけです。

## 記録とチャレンジの共有

主線の進行、現在の主線セッション、設定、最少手数、ヒント使用の記録はブラウザーに保存します。アカウントやオンライン順位表はありません。日替わり問題は **UTC の日付**で決まり、手元の日付と異なることがあります。

この[魂のペアがある庭](https://halloween-3d.crazy3d.org/#p=v1.3.26.0-8)のリンクには、開始盤面、サイズ、ペアの情報が含まれます。途中の手順やリプレイは送らず、相手も同じ初期問題から考えられます。

## よくある質問

### WebGL が使えなくても遊べますか？

はい。WebGL のコンテキストを作れない場合は、Canvas で同じカメラと立体形状を投影します。完全に遊べる平面2D盤面もあり、描画の初期化に失敗した場合はこちらを使えます。

### ヒントは決まった攻略手順をなぞるだけですか？

いいえ。現在の盤面を解き直して、最少クリック数のルートを求めます。試行錯誤や Undo のあとにも対応します。

### WebGL の見た目まで検証済みですか？

現在のブラウザー確認は WebGL のない環境で、ソフトウェア3Dと平面表示を対象にしています。実機の WebGL 表示や GPU のフレームレートを保証するものではありません。

## ローカルで実行・サイトに埋め込む

リポジトリのルートで HTTP サーバーを起動します。

```sh
python3 -m http.server 4173
```

**http://localhost:4173/** を開いてください。ビルドや依存パッケージは不要です。`file://` では JavaScript モジュールを読み込めない場合があります。

Node で付属のチェックを実行します。

```sh
npm test
```

隣接ルール、再帰しない魂のペア、操作の可逆性、主線すべての解法、3×3 の最少手数、不正リンク、365日分の問題を確認します。投影では回転、サイズ変更、小窓の境界、奥行きの順序も対象です。

```html
<iframe src="https://halloween-3d.crazy3d.org/?embed=1"
  title="Ghost Lanterns 3D"
  style="display:block;width:100%;height:540px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

確認したブラウザー寸法は **960×540、390×460、390×300、844×340**。iframe 自体の寸法に合わせて配置し、`?embed=1` で小窓向け表示を指定できます。Canvas と JavaScript モジュールは必要ですが、WebGL は任意です。音は操作後に始まり、無効にもできます。

寸法、保存、フォーカス、権限は[埋め込みガイド](EMBEDDING.md)へ。親サイトのツールバーを除いた高さを iframe に割り当ててください。
