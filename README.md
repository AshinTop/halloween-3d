# Ghost Lanterns 3D · 幽灵灯阵

为 [crazy3d.org](https://crazy3d.org) 专题制作的完整静态万圣节翻灯解谜，属于 Midnight Candy Club 系列。

## 运行

```sh
python3 -m http.server 4173
# 打开 http://localhost:4173
npm test
```

不需要安装依赖或构建。ES modules 需要 HTTP 服务。

## 玩法与完成内容

- 传统 Lights Out：点击一盏灯，翻转自己和上下左右的灯，目标是全部点亮。
- 十二个渐进关卡，覆盖 3×3 和 4×4 花园。第五关起加入原创“灵魂灯”规则：直接点击一盏紫色标记的灯，它的伙伴额外翻转一次；邻灯不继续传播。
- 真正 WebGL 的原创南瓜几何、立体底座、法线光照、正交镜头和花园旋转；没有外部 3D 库或素材。
- WebGL 不可用时，Canvas 使用同一三维坐标、镜头与法线光照，以三角面深度排序绘制低多边形花园。另有可随时切换的完整二维棋盘。
- 撤销、重开、实时求解提示、最短解参考、按 UTC 更新的每日花园、题面分享链接。
- 英文与简体中文、触屏/鼠标/键盘、可关闭音效、减少动态效果支持。
- 当前关卡进度与本地最佳步数保存于浏览器，无账户或后台。

## 逻辑验证

线性代数求解器在 GF(2) 上求解，再枚举零空间以找到最短点击集合。规则是确定、可交换且每次点击自反的。测试覆盖传统邻接、灵魂灯只翻转一次、不递归、可逆移动、全部关卡完整解、3×3 最短解的独立枚举验证、非法分享参数，以及 365 个每日题面的完整解。

`renderer.js` 优先使用原生 WebGL，并具备 Canvas 软件三维投影。纯矩阵测试覆盖镜头旋转、窄屏包围框、尺寸变化和深度顺序。最终 GPU 帧率、触控准确性和视觉布局仍应在实际设备上检查；软件三维与二维模式不依赖 WebGL。接入尺寸与验证边界见 `EMBEDDING.md`。未来作品方向是 Pumpkin Post 3D（午夜南瓜快递），本仓库目前交付灯阵游戏。
